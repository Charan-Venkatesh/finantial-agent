## 2024-03-24 - Accessible Input Component
**Learning:** React's `useId` hook combined with `aria-describedby` provides a robust pattern for linking inputs with their helper text and error messages. This ensures that screen reader users receive context about the input's purpose and state immediately.
**Action:** Use this pattern for all form inputs in future projects: generate a unique ID for the input, derive IDs for helpers/errors, and link them programmatically.
